# Security policy

## Supported versions

Security fixes are applied to the latest public release.

## Reporting a vulnerability

Do not open an issue for a suspected vulnerability. Use GitHub's confidential
security-advisory reporting interface for this repository. Include affected
versions, reproduction steps, potential impact, and any suggested mitigation.

SHAP Prism is a local plotting library. It does not make network requests,
execute supplied code, train models, or transmit SHAP values. Reports about
dependency vulnerabilities should identify the affected dependency and
whether the issue is reachable through SHAP Prism.
