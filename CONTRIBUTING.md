# Contributing

Bug reports, focused fixes, documentation improvements, and reproducible
examples are welcome.

1. Open an issue describing the observed behavior, expected behavior, Python
   version, dependency versions, and a minimal reproducible input.
2. Create a focused branch and keep unrelated formatting changes separate.
3. Add or update tests for behavior changes.
4. Run the verification steps in `DEVELOPMENT.md`.
5. Document user-visible changes in `CHANGELOG.md`.

Do not include confidential data, unpublished manuscript files, credentials,
or third-party data without clear redistribution terms in issues or pull
requests. By contributing, you agree that your contribution is distributed
under this repository's MIT License.
